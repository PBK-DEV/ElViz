# Installation

## Stable release

To install elviz, run this command in your terminal:

```sh
uv add ElViz
```

Or if you prefer to use `pip`:

```sh
pip install ElViz
```

## From source

The source files for elviz can be downloaded from the [Github repo](https://github.com/PBK-DEV/ElViz).

You can either clone the public repository:

```sh
git clone https://github.com/PBK-DEV/ElViz
```

Or download the [tarball](https://github.com/PBK-DEV/ElViz/tarball/main):

```sh
curl -OJL https://github.com/PBK-DEV/ElViz/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd ElViz
uv sync
```
